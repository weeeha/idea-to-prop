# MTL63-RG02: first worked example

RG02 is a nonfunctional fictional film-prop study used to shape this workflow. This page describes the existing work as of 2026-10-26. Its source assets and fabrication files remain in the film workspace; this public example contains no model or print downloads.

## Existing work

The study progressed from concept-image selection to a textured TRELLIS model, visual review in Blender, and separate print preparation. An earlier procedural interpretation was retained as a separate edition. The user preferred the TRELLIS appearance for continued print preparation.

The print derivative includes repaired geometry, adjusted hand-fit proportions, separated parts, slicer projects, and a small fit-test package. Its saved documentation records mesh and slicer checks. Those checks are historical evidence from the study; this documentation PR does not rerun them or certify the resulting physical object.

## What the study taught us

- A selected image and a generated model need separate review: hidden surfaces were inferred.
- A textured visual mesh can need significant repair before fabrication.
- Print preparation can soften surface details and change local proportions.
- A small fit test is a separate deliverable from the full print package.
- The generated model, visual reference, and physical derivative need explicit relationships.
